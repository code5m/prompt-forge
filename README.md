# Prompt Forge 工作台

一个无依赖的静态网页工作台，用于将图片与视频创意组合为可复制提示词。

## 能力

- 图片 / 视频模式：视频模式额外提供镜头运动、动作与时长字段。
- 优先使用父目录（在原素材仓库中运行）或当前目录（独立 GitHub 仓库）下的 `hot_prompts.json` 加载现有提示词灵感库；加载失败时自动使用内置示例。
- 分类浏览、随机起点、复制、浏览器本地收藏与 JSON 导出。
- 生成结果为模型无关的英文提示词底稿，适配图片或视频模型时可按各服务商语法微调。

## 本地运行

在 `workbench/` 目录运行：

```bash
python3 -m http.server 8080
```

然后打开 `http://localhost:8080/`。独立版仓库将提示词数据置于同一目录；原素材仓库中的工作台也可从根目录启动并打开 `/workbench/`。


## 双语 AI 优化工作台（新增）

页面保留原有图片/视频拼接器及灵感库，在下方新增「双语优化 · 批量审核 · 版本差异 · 图片对比」：
1. 先从原生成器导入（会明确标记中文仅为主体）或新建完整中英提示词方案。
2. 保存 V1。勾选最多 5 个方案进行 AI 审核，审查中英文一致性、镜头/构图/光线、可执行性和潜在缺陷。
3. 每项审核显示原文与候选的红绿字符差异、评分、缺陷及修改原因。点击「接受优化」才会创建 V2；拒绝不修改原版。也可任意手动保存新版本。
4. 分别选择优化前和优化后版本，在中文与英文两个面板中查看差异；恢复旧版时会新建版本，不覆盖历史。
5. 通过 SenseNova U1.5 Lite 生成 A/B 图片，模型和参数一致，自动扩写关闭；选择赢家并留下实验结论。支持导出/导入 JSON 版本备份。

注意：从旧生成器导入的中文描述可能只是“主体”，**不等于**完整英文提示词的中文翻译；需要人工校对或经过真实 AI 审核。

## 本地启动（建议 Node.js 20+）

仓库根目录（即 package.json 所在目录）执行：

```bash
npm test
npm start
```

打开 http://127.0.0.1:8080/ 。纯静态 HTTP 仍可使用编辑、版本、灵感库、差异与 JSON 备份，但不能进行真实 AI 审核/生图。

### 日日新真实 API

先在 [SenseNova 控制台](https://platform.sensenova.cn) 创建 API Key（不需要将 Key 发送给 AI，也不要提交到 GitHub），在**自己电脑的终端**配置环境变量，然后运行服务端：

```bash
export SENSENOVA_API_KEY="sk-你的密钥"
npm start
```

服务端只在 `127.0.0.1:8080` 监听；密钥不返回浏览器。真实审核使用 `sensenova-6.8-flash-lite`，图片生成使用 `sensenova-u1.5-lite`。图片端点 `POST https://token.sensenova.cn/v1/images/generations`，默认开启水印、关闭 prompt_extend；图片采用 `b64_json` 响应以免生成链接过期。不同账户的模型权限、费用以及价格上限以服务商控制台为准。

当你的套餐只具备图像模型权限、没有对应文字审核模型权限时：**图片接口可单独使用，批量 AI 审核会明确报错**。不要将图像模型当作聊天模型使用。代码使用固定允许列表而非接收任意 URL，从而避免外部代理滥用。单机每分钟默认最多 12 次 API 请求，最多同时 2 个请求，每批审查 5 条，实际生成图片一对为 2 次调用。

### 模拟模式：不消耗 Token

```bash
PROMPT_FORGE_MOCK_AI=1 npm start
```

模拟模式显示的审查意见及图片均明确标记“模拟”，只能用于验收交互，不代表真实生成质量。

### 网络部署安全

项目默认**只允许本机访问**。如要发布到互联网，应另行配置 HTTPS 反向代理、正式用户登录与配额系统；设置 `WORKBENCH_ACCESS_TOKEN` 是最低限度的单用户保护，而**不是多用户公网平台的完整登录/防滥用方案**。切勿在公网上裸露带付费能力的图像接口。服务器不提供通过 HTTP 修改 Key 的接口。

### 数据与可重复性边界

- 历史版本和文字实验记录存浏览器 localStorage；建议定期导出备份，清除浏览器缓存会丢失未备份记录。
- 为避免 localStorage 迅速耗尽，大图只保留在当前页面会话；网页不承诺持久化原始图片。关闭页面前请自行保存图片；备份 JSON **不包含图片二进制**。
- A/B 固定模型、尺寸、文字版本与 `prompt_extend=false`。模型仍有随机性，单张胜负只是主观参考，不代表统计显著性；更严格对比须在服务提供可用 seed 参数时固定随机种子，并进行重复样本评估。
- 未实测真实 API Key 时，不能宣称实际请求或计费结果通过。
